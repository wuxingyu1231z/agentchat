# 论文调研助手

重启新版后端后，在智能体列表或聊天输入框旁选择“论文调研助手”，输入研究主题即可。通用助手与已有自建智能体继续保留。

## 使用流程

1. 输入主题及关注点，例如“调研强化学习 Agent 的工具失败恢复方法，比较方法、评测数据集和局限性”。
2. 助手生成 2–4 个互补子问题及英文检索式，分别检索 arXiv、Crossref 和已配置的网页搜索服务。默认先搜集候选，再按相关性及子问题覆盖选择最多 6 篇论文、2 个补充网页。
3. 重新查询论文元数据核对身份，尝试读取公开 PDF，并检查首页是否匹配标题或 DOI；不匹配时标为来源身份待核实。不可访问、加密、扫描件或只有摘要时明确记录阅读限制。PDF 最多提取 300 页或 200 万字符，单个文件最多 12 MB；分析时按方向及方法、数据集、实验、局限性筛选逐字片段，保存原件引用、页码与偏移，不提供 OCR 或付费墙绕过。具体容量、检索和工作记忆见 [上下文机制](context-management.md)。
4. 从来源中提取方法、数据集、实验结论、局限性，逐条保存原文片段、来源 ID 与页码。
5. 先进行逐字原文及页码匹配，再由独立模型调用检查原文是否支持候选陈述。未通过的内容不进入报告结论或比较表。
6. 输出 Markdown 报告，包含检索范围、比较表、带证据的结论、原始链接、获取时间、内容 SHA256 和覆盖限制。报告采用确定性排版，避免在最终自由生成阶段再引入未经核验的新结论。

这是一轮有预算限制的辅助调研，不等于穷尽文献的系统综述。模型辅助核验不能代替独立复现实验或专家判断；不同数据集或设置下的实验数值不能直接排名。

## 按需多 Agent

主 Agent 在规划时标出问题的工作量、独立性和前置依赖，随后由确定性规则决定是否委派。默认只有至少 3 个子问题、其中至少 2 项是无前置依赖、检索范围不高度重合且需要多来源筛选的实质工作时，才启用检索子 Agent。一次研究方向最多 2 个子 Agent，同时运行上限为 2。简单查找、少量问题、相互依赖或高度重复的检索由主 Agent 处理，并在记录中解释没有委派的原因。

每个检索子 Agent 有独立的小型状态图和模型上下文，只看到父研究方向、分配的子问题及该问题取得的候选来源。它负责只读检索和候选相关性筛选；没有递归委派或外部写操作入口。候选过少时直接交回主 Agent，避免一次无意义的模型调用。主 Agent 汇总去重、按前置依赖继续未委派的问题，统一阅读、比较、核验原文和生成最终报告。

子 Agent 的身份、父任务、分工、状态、来源数、脱敏异常及时间保存在研究工作区，步骤结果独立缓存。页面可展开研究进度查看分工；JSON 导出包含所有子任务记录。子 Agent 失败时主 Agent 复用已有检索记录接管，其他子任务不丢弃。暂停时各子 Agent 在当前步骤返回后协作停止，再由父图统一持久化中断；继续后复用已保存的检索和筛选结果。异常退出同样通过父任务恢复，不会产生脱离父任务继续执行的后台子任务。

## 中断、恢复与调整方向

关闭页面、刷新或切换会话不会取消后台任务。业务数据库的 `research_workspace` 保存节点结果，`agent_run_event` 保存执行轨迹，LangGraph 的下一步执行位置保存到现有检查点文件。备份时同时保留业务数据库和检查点文件。

点击“暂停”，当前操作返回后会在步骤边界暂停。暂停、中断或失败时可在“调整研究方向”中填写新的范围再点击“继续任务”；留空则按原方向恢复。调整方向后重新规划和检索，旧计划、原始检索结果和阅读记录保留；已成功读取的同一来源可以复用。每个任务最多修改方向 10 次。完成后的进一步研究可在同一会话继续提问，规划会参考近期会话内容。

网页搜索依赖已配置的 Tavily 或 Bocha，见 [简易配置说明](simple-config.md)。二者都未配置时，记录网页搜索缺失并继续学术检索，不把学术检索表述为全网搜索。arXiv / Crossref 与论文站点需要网络可达；网络错误、限流等进行有界重试。API 或 PDF 读取失败会保留失败记录并明确标出证据缺口。

报告生成后可下载 Markdown 报告，研究过程中的资料可随时导出 JSON，原有 JSONL 执行轨迹导出继续可用。重新打开已完成的论文会话也能找到最近一次任务的下载入口。

## 记录与接口

研究 JSON 包括各版本计划、检索原始元数据、来源 URL 与内容哈希、读取页文本、结构化候选陈述、核验结果、方向修改记录和报告。执行轨迹记录步骤开始、结束、异常及时间。它们只允许任务所属账号访问，不能提交到公共 Git 仓库。

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/v1/runs` | `agent_id: "paper-research"` 创建专用调研任务 |
| POST | `/api/v1/runs/{id}/resume` | 可选 `research_direction` 修改研究方向 |
| GET | `/api/v1/runs/latest?conversation_id=...` | 找回最近一次任务及报告入口 |
| GET | `/api/v1/runs/{id}/research` | 查看完整研究工作区 |
| GET | `/api/v1/runs/{id}/research/export?format=markdown` | 下载报告，未生成时返回 409 |
| GET | `/api/v1/runs/{id}/research/export?format=json` | 下载检索、阅读、核验和方向记录 |

公开网络读取只允许 HTTP(S) 的公开地址，拒绝本机、内网地址、携带账号密码的 URL 和异常端口；重定向重新校验，连接使用校验后的 DNS 地址。

实现参考：[LangGraph 持久化](https://docs.langchain.com/oss/python/langgraph/persistence)、[中断恢复](https://docs.langchain.com/oss/python/langgraph/interrupts)、[子图协作](https://docs.langchain.com/oss/python/langgraph/use-subgraphs)、[arXiv API](https://info.arxiv.org/help/api/user-manual.html)、[Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api)。
