# 通用助手、专用助手与可恢复任务

默认入口是 `general`（通用助手），自动加载当前用户已启用的工具。工具页可以启用或停用工具，不再为每个工具生成一个智能体。智能体创建、编辑和对话选择器继续保留。专用的 `paper-research`（论文调研助手）使用独立状态图执行规划、检索、阅读和证据核验，详见 [论文调研助手](paper-research.md)。

首次启动新版后端时，原先自动生成的“单工具 + 助手”预设会存入 `retired_agent` 归档表，然后从智能体列表移除。迁移只处理未定制的自动预设，保留自建及已修改配置的智能体。相关会话转为通用助手，历史消息保留原助手身份。

## 存储

业务数据库新增任务、执行事件、工具调用账本、预设归档、工具开关五张表。默认简易模式使用 SQLite；已有 MySQL 配置继续保存业务表。

上下文原件、检索片段和版本记忆另外保存到三张业务表。容量管理、历史召回和论文证据回读见 [上下文机制](context-management.md)。

LangGraph 官方 `AsyncSqliteSaver` 单独保存执行检查点。默认文件位于业务 SQLite 旁的 `agentchat-checkpoints.sqlite`；其他业务数据库默认使用后端 `data/agentchat-checkpoints.sqlite`。可通过 `AGENTCHAT_CHECKPOINT_DB` 指定绝对路径。备份和部署时必须同时保留业务数据库及检查点文件，容器需挂载持久化目录。当前实现适合单机部署；多个进程应共享同一本地检查点文件，不适合多主机独立文件部署。

数据库是恢复依据。JSONL 是可导出的执行事件记录，不用于恢复；Markdown 可用于报告等最终产物。事件导出经过凭据字段脱敏，数据库中的原始模型输入和工具结果仍应作为私人数据管理。数据库、本地配置和运行目录不应提交 Git 或打包进镜像。

## 执行与恢复

- 浏览器连接只订阅任务进度，刷新或关闭页面不会取消后台任务。重新打开会话可找回未完成任务。
- 暂停在模型或工具步骤边界生效，正在执行的外部调用会先等待返回。结束任务也不会撤销已经发生的外部操作。
- 后端正常关闭时保存中断状态；异常退出通过 60 秒租约过期识别中断，每 15 秒巡检。识别后点击“继续任务”从检查点恢复。
- 同一会话只允许一个未完成任务。继续或结束任务后才能发送新问题或切换助手。
- 已完成的工具调用按调用 ID 复用账本结果；未进入检查点的模型片段可能重新生成，页面会替换该部分，避免拼接出重复回答。
- 已知只读内置工具遇到超时、限流或服务暂时不可用，最多执行 3 次。参数、鉴权等其他异常作为失败结果交给模型处理。模型调用最多额外重试 2 次；单次模型调用限时 120 秒，只读工具 60 秒，其他工具 180 秒。同步工具还需设置自身网络超时，因为取消等待不能终止其后台线程。
- 工具执行前先按公开参数 schema 校验。可确定的类型表示错误会规范化，例如 `web_search.time_range` 的字符串 `"null"` 转为空值且不向搜索 SDK 传入时间限制。不能直接规范的错误返回字段要求，由主模型在同一任务内修正后再次调用；每种工具初次参数失败后最多允许两次纠错，不原样重复执行。参数未通过校验时不会进入工具执行体，也不会把未执行的写操作误标为结果不确定。没有依据的必填参数需要向用户澄清。
- 邮件、文件操作、自定义 OpenAPI、MCP 等未经确认只读的工具，异常或执行中断后可能已经生效，标记为“结果不确定”。必须人工核实并选择“跳过此步骤”或“核实后重试”，每次重试再失败仍需重新确认。无法承诺外部服务的严格一次执行；若对方支持幂等键，应进一步在对应工具中使用。
- 每任务最多 20 个不同工具调用和 12 个模型工具决策轮次，避免无限循环。

## 接口

正式聊天页面使用以下任务接口（均需登录，按用户隔离）：

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/v1/runs` | 创建任务，支持 `request_id` 幂等提交及 `agent_id` 选择 |
| GET | `/api/v1/runs/active?conversation_id=...` | 查找会话未完成任务 |
| GET | `/api/v1/runs/{id}` | 查询状态、回答和待确认工具 |
| GET | `/api/v1/runs/{id}/events` | SSE 重放与实时事件，支持 `after` / `Last-Event-ID` |
| POST | `/api/v1/runs/{id}/pause` | 请求暂停 |
| POST | `/api/v1/runs/{id}/cancel` | 请求结束 |
| POST | `/api/v1/runs/{id}/resume` | 恢复，`decisions` 按工具调用 ID 指定 `skip` / `retry` |
| GET | `/api/v1/runs/{id}/export` | 导出 JSONL 执行事件 |
| PATCH | `/api/v1/tool/enabled` | 设置当前用户工具开关 |

旧 `/api/v1/completion` 保留兼容，其 HTTP 执行方式不提供上述任务检查点恢复能力。

参数兼容性参考：[Tavily Search 参数](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
